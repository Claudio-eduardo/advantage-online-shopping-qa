# 📋 Casos de Teste Manuais

Nesta pasta encontram-se os casos de teste manuais elaborados e executados durante a validação da aplicação **Advantage Online Shopping**.

Os cenários foram selecionados com o objetivo de validar funcionalidades essenciais do fluxo de compra, desde a autenticação do usuário até a conclusão do pedido.

---

# Casos documentados

- [CT-001 – Login com sucesso](./CT-001_Login_Com_Sucesso/)
- [CT-002 – Adicionar produto ao carrinho](./CT-002_Adicionar_Produto_Ao_Carrinho/)
- [CT-003 – Finalizar compra com dados válidos](./CT-003_Finalizar_Compra_Com_Dados_Validos/)
- [CT-004 – Editar quantidade do produto no carrinho](./CT-004_Editar_Quantidade_Do_Produto/)
- [CT-005 – Aplicar filtro por fabricante](./CT-005_Aplicar_Filtro_Por_Fabricante/)

---

# Estrutura dos casos de teste

Cada caso de teste possui documentação contendo:

- Objetivo;
- Tipo de teste;
- Prioridade;
- Pré-condições;
- Massa de teste;
- Passos para execução;
- Resultado esperado;
- Critério de aprovação;
- Resultado da execução;
- Observações.

---

# Ambiente de execução

- **Aplicação:** Advantage Online Shopping
- **Plataforma:** Web
- **Dispositivo:** Desktop/Notebook
- **Sistema operacional:** Windows 11
- **Navegador:** Google Chrome

---

# Resultado geral

Os cinco casos de teste foram executados manualmente para validar funcionalidades fundamentais da aplicação.

Durante a execução, também foram identificados comportamentos inesperados, documentados separadamente na seção de relatórios de bugs do repositório.
