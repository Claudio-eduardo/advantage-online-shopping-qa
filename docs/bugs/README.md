# 🐞 Relatórios de Bugs

Nesta pasta encontram-se todos os bugs identificados durante a execução de testes manuais na aplicação **Advantage Online Shopping**.

Todos os relatórios foram documentados seguindo um padrão único, contendo descrição detalhada do defeito, ambiente, passos para reprodução, resultados esperados e obtidos, classificação de severidade e prioridade, além de evidências visuais (imagens e/ou GIFs).

# Estrutura dos relatórios

Cada relatório segue um padrão de documentação contendo:

- Resumo
- Ambiente
- Pré-condições
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Impacto
- Severidade
- Prioridade
- Evidências (imagens e/ou GIF de reprodução)
- Observações

---

# Objetivo

Este conjunto de relatórios foi elaborado durante a execução de **testes manuais** na aplicação **Advantage Online Shopping**, com foco na identificação, documentação e classificação de defeitos utilizando boas práticas de **Quality Assurance (QA)**.

Cada bug foi documentado de forma padronizada para facilitar sua reprodução, análise e comunicação com equipes de desenvolvimento, servindo também como demonstração prática de habilidades em testes manuais, documentação técnica e elaboração de evidências de defeitos.
