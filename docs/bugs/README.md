## Estrutura dos relatórios

Todos os bugs seguem um padrão de documentação contendo:

- Resumo
- Ambiente
- Pré-condições
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Impacto
- Severidade
- Prioridade
- Evidências (imagens e/ou GIF de reprodução)
- Observações

---

## Objetivo

Este repositório reúne defeitos identificados durante a execução de **testes manuais** na aplicação **Advantage Online Shopping**.

Cada bug foi documentado seguindo um padrão consistente, contendo descrição detalhada, passos de reprodução, classificação da severidade e prioridade, além de evidências visuais para facilitar a análise e a reprodução do problema por equipes de desenvolvimento e Quality Assurance.
