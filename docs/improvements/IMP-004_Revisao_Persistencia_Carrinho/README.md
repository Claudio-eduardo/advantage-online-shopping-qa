# IMP-004 – Revisão da persistência do carrinho

---

# Área da aplicação

Carrinho de Compras

---

# Descrição da melhoria

Revisar o mecanismo responsável pela persistência do carrinho para usuários convidados, garantindo que todos os produtos permaneçam armazenados durante a navegação e atualização da página.

---

# Justificativa

A consistência do carrinho é fundamental para evitar perda de informações e abandono do processo de compra.

Uma estratégia de persistência mais robusta aumenta a confiabilidade da aplicação.

---

# Impacto esperado

- Maior estabilidade do carrinho.
- Redução de perda de itens.
- Melhor experiência de compra.

---

# Tipo de melhoria

Arquitetura / Persistência
