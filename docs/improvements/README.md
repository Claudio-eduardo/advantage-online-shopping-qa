# 💡 Sugestões de Melhoria

Esta pasta contém sugestões de melhorias identificadas durante a execução dos testes manuais na aplicação **Advantage Online Shopping**.

As melhorias apresentadas não representam defeitos da aplicação, mas oportunidades para aumentar a usabilidade, consistência, confiabilidade e experiência do usuário.
